# Barsaat OS

A monsoon operating system for the browser: rain on the glass, a taxi meter running, and a handful of apps that talk to each other.

**Meet Sid** plays a four-aces card trick, then unfolds Sid's unreasonably long business card: a 3D letterpress card on a walnut desk that won't stop unfolding, because the career won't fit on it. The card also runs on its own: [sids-card.html](sids-card.html).

Two static files, no build step, no server:

- `index.html`: Barsaat OS
- `sids-card.html`: Sid's Card, a single file with everything inlined (Three.js, fonts, photos)

To publish with GitHub Pages: Settings → Pages → Deploy from a branch → `main` / root.
